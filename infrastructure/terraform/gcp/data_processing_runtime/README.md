# Stage 11 infrastructure (plan-only)
This isolated Terraform root proposes a new Dataflow subnet with Private Google Access and a dedicated worker identity. It does **not** create VMs, NAT, IAM bindings, Pub/Sub topics, BigQuery datasets, buckets, watchdogs or Dataflow jobs. Do not apply until reviewing the plan, network CIDR overlap, regional quotas, service account impersonation, resource-level permissions, package staging connectivity, server-side watchdog and cleanup. A private worker with no NAT cannot fetch arbitrary packages from the public internet; use pre-staged dependencies or approved egress architecture.
